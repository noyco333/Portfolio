A movement-based speedrunning game with pixelated neo-retro aesthetics, inspired by games like ULTRAKILL and Neon White.
![](https://youtu.be/f4ELw4ECr2o)

The game features original 3d characters and music.

Though the game is in first person, the player character *Kufu* is fully modeled since the game features sliding effects that shows their legs.
